# qa3-tools v0.1.0

First public release of the QA3 defensive security CLI.

## Changes

- Adds `qa3 header-audit` for explicit, single-target HTTPS security-header and TLS inspection.
- Adds human-readable and JSON output.
- Adds bounded timeouts, redirect limits, response-header limits, and private-network guardrails.
- Adds specifications, threat-boundary documentation, tests, secret-pattern scanning, and vulnerability scanning in CI.

## Compatibility

Prebuilt binaries are produced for Linux and macOS on amd64 and arm64, and Windows on amd64 and arm64. Source verification and release builds use Go 1.26.6.

## Breaking changes

None. This is the first public release.

## Security

The command is read-only by design, accepts exactly one explicit HTTPS target, verifies TLS certificates normally, requires TLS 1.2 or newer, and blocks loopback/private destinations unless explicitly allowed. Link-local destinations remain blocked.

The release workflow must pass `govulncheck` before artifacts are published.

## Limitations

`header-audit` reports observable HTTP response headers and TLS state; it does not prove overall application security or compliance. It does not crawl, scan ports, authenticate, submit forms, or attempt exploitation.

Release artifacts include SHA-256 checksums. Binary and tag signing are not enabled for v0.1.0.
